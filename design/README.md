## 怎么跑原型

直接双击 `preview/index.html`（或在本机浏览器打开）。**无需 npm install、无 CDN 依赖**。

- 右上角切换角色：校长 / 教务主任 / 年级组长 / 教师 / 学生 —— 同一入口不同内容（AC-DD2-1）
- 大屏顶部「学期 / 自然月」切换器：默认学期（AC-DD1-2）
- 点铃铛：消息列表只有标题，点击跳业务详情（docs/15 不做正文预览）
- 教师工作台点「物资领用申请」→ 数量填 >3 → 提交：演示 40903 库存不足三段式反馈
- 教师工作台点「会议室预约」→ 时段选「周二 第 7 节」→ 提交：演示 40901 课表占用（教师为 SELF 范围，占用来源已脱敏为占位文案、不给课表入口）+ 替代时段一键改约

## 怎么落进 vue-pure-admin

1. `design/src/` 下的内容按目录结构整体拷到 `src/`（`design/src/views/...` → `src/views/...`）。
2. 在 `src/style/index.scss` 顶部加一行 `@import "@/design/tokens.css";`（或 `main.ts` 里 `import "@/design/tokens.css"`）。
3. 安装 ECharts：`pnpm add echarts`（`useEChart.ts` 直接 `import * as echarts from "echarts"`）。
4. 路由按 docs/03 菜单树的 `path` 注册（本目录的 `views/` 已按菜单路径命名）。
5. `v-auth` 指令沿用 vue-pure-admin 自带实现；`@/utils/http` 沿用自带 axios 封装。

## 设计硬约束（复述，改动这些代码前先读 docs/16）

1. 前端**不做**数据权限过滤、不做聚合、不做时间口径重排 —— 全部由服务端完成。
2. 任何趋势图 / 报表**默认学期口径**，自然月仅传 `dim=MONTH` 让服务端重排。
3. 大屏与下钻**不得出现**平台级配置对象（字典 / 流程模板 / 菜单 / 角色 / 部门）。
4. 教师端高频事务**≤3 步**；改动 `QuickApply/schemas.ts` 后必须复核步数声明 `stepText`。
5. 冲突与并发失败**禁止**只弹「操作失败」，必须走 `ConflictAlert` 三段式（40901/40902/40903/40904）。
6. **越权红线**：`occupiedBy`、占用矩阵里的占用人身份都是他人课表/行程数据——服务端按数据范围分级脱敏，前端必须兼容缺失/降级（兜底占位文案），且降级时不给「查看该场地课表」入口。前端不得缓存或另存这些字段。
