# 中学校务数字化平台 · 数据大屏 PRD（分角色驾驶舱）

> 阶段：Phase 1 需求（第七模块，跨域聚合层）| 门禁：门禁 1（需求门禁）
> 定位：数据大屏是硬指标①「校长端核心指标不离开系统」的集中载体，同时为各角色提供「领域运营看板」。
> 复用：六域 PRD 已有指标（docs/01/06/08/09/10/11）、三级权限（docs/04）、RBAC（docs/03）。

---

## 一、目标用户与场景（分角色视角）

数据大屏**不做独立业务数据**，只聚合展示六域已产生的数据，按角色数据权限自动过滤。

| 角色 | 大屏定位 | 看到什么 |
| --- | --- | --- |
| 校长 R-PRINCIPAL | 全校驾驶舱 | 六域 KPI 总览 + 全校异常预警 + 趋势 |
| 副校长 R-VP | 分管领域大屏 | 可配置分管领域（如分管德育/后勤） |
| 后勤 R-LOGISTICS | 后勤运营大屏 | 采购进度 / 物资库存 / 报修工单 |
| 德育处 R-MORAL | 德育运营大屏 | 请假 / 违纪 / 评优统计 |
| 党政办 R-PARTY | 党政运营大屏 | 公告已读率 / 公文流转 / 会议值班 |
| 教务主任 R-DEAN | 教务运营大屏 | 课表完整率 / 排课冲突数 / 软约束违规数 / 调课·代课次数 / 教师周课时分布 |
| 年级组长 R-GRADE | 本年级大屏 | 本年级请假/违纪/体测/课表 |
| 教研组长 R-SUBJECT | 本组大屏 | 本组课时 / 课题 / 资源 |
| 教师 R-TEACHER | 个人工作台 | 本人课表 + 本班动态（非大屏） |
| 学生 / 家长 | 个人中心 | 本人 / 子女记录（无大屏） |

## 二、需求清单（REQ-DD，标 P0/P1）

### DD. 数据大屏

- **REQ-DD1｜大屏框架**：统一大屏布局（顶部 KPI 指标卡 + 中部图表区 + 底部趋势/明细），支持图表类型（趋势折线、分布柱状、对比条形、达标雷达）。全体角色。P0。**趋势图与图表区统一提供「学期 / 自然月」维度切换器**——默认按**当前学期**聚合，自然月仅作**展示维度**（口径依据 docs/04 §1.8）。
- **REQ-DD2｜分角色视图**：按登录角色自动加载对应大屏模板，无需手动切换；同一页面不同角色看到不同内容。全体角色。P0。
- **REQ-DD3｜指标卡片**：核心指标以卡片呈现（当前值 / 环比 / 同比 / 趋势箭头），点击可下钻。校长+处室。P0。
- **REQ-DD4｜异常预警**：超阈值指标高亮标红，并汇总预警列表（超期审批、滞留公文、排课冲突、库存不足、违纪高频、体测不达标集中班级等）。校长+处室。P0。
- **REQ-DD5｜数据范围联动**：大屏所有指标随角色数据权限自动过滤（组织型/关系型/角色授权型），**服务端聚合**，不允许前端拉全量再算。全体角色。P0。
- **REQ-DD6｜下钻明细**：从大屏指标点击下钻到对应明细列表（如「违纪统计」下钻到违纪记录列表），明细仍受数据权限约束。校长+处室。P0。
- **REQ-DD7｜刷新与时效**：大屏定时刷新（可配，默认 60s），每个指标标注「数据截止时间」，保证口径可信。全体角色。P1。

## 三、验收标准（含两条硬指标）

**两条硬指标：**
- 硬指标①【校长端】：校长在数据大屏上**一次看到六域核心指标 + 异常预警**，任一指标无需离开系统去微信/电话追问。
- 硬指标②【高频事务 ≤3 步】：处室/教师打开本角色大屏 ≤2 步（登录后首屏即大屏或一键进入）。

**逐条可测试验收标准：**
- AC-DD1-1：大屏支持 KPI 卡、趋势折线、分布柱状、对比条形、达标雷达至少四类图表。
- AC-DD1-2：大屏趋势图 / 图表区提供「**学期 / 自然月**」**维度切换器**，默认按**当前学期**聚合；切到自然月后**仅重排展示粒度**——聚合结果、数据可见范围与越权判定均不变（对齐 docs/04 §1.8 统一时间口径，六域不自造时间维度）。
- AC-DD2-1：校长登录看到全校驾驶舱，年级组长登录看到本年级大屏，同一入口不同角色内容不同。✅硬指标①
- AC-DD2-2：处室打开本角色大屏、教师打开个人工作台均 ≤2 步（登录后首屏即本角色视图，或工作台一键进入），无需先翻菜单再选模板。✅硬指标②
- AC-DD3-1：指标卡片显示当前值 + 环比/同比 + 趋势方向，数据与明细一致。
- AC-DD4-1：超阈值指标自动标红进入预警列表，点击可定位到对应业务对象。
- AC-DD5-1：大屏指标随数据权限过滤——校长看全校、年级组长只看到本年级、处室只看到本领域，越权数据不出现在大屏（服务端聚合）。✅硬指标①
- **AC-DD5-2**：任一角色的大屏指标与**下钻明细**中均**不包含平台级配置类数据**——数据字典（M0505）、流程模板（M0507）、菜单 / 角色 / 部门等对象**不得作为指标，也不得出现在下钻结果中**；以**非 R-ADMIN 角色**登录后请求大屏接口，返回结果（含下钻）不含上述对象，否则不通过（此类仅 R-ADMIN 可见，见 docs/03 注 5）。
- AC-DD6-1：大屏指标可下钻到明细列表，明细仍受数据权限约束（越权查询服务端拒绝 40303/40304）。
- AC-DD7-1：每个指标标注数据截止时间，定时刷新间隔可配置。

> 注（统一时间口径）：大屏所有趋势图 / 图表区均提供「**学期 / 自然月**」**维度切换器**，默认**学期**口径；自然月**仅为展示维度**，不改变数据归属、聚合结果与权限判定口径（口径依据 docs/04 §1.8，本文档只引用不自造时间维度）。
> 注（硬指标挂点）：硬指标①落点为 **AC-DD2-1**（校长一次看到六域 KPI + 异常预警）与 **AC-DD5-1**（数据随权限过滤、越权数据不出现，服务端聚合）——两项共同支撑"任一指标无需离开系统追问"；硬指标②落点为 **AC-DD2-2**（打开本角色大屏 ≤2 步）。

## 四、明确排除项（本次不做什么）

1. 不含拖拽式自定义大屏编辑器（首版按角色预置固定模板，不做用户自定义布局）。
2. 不含实时流式数据推送（定时刷新即可，不做 WebSocket 实时流）。
3. 不含 BI 自助分析/多维透视（不做拖拽维度自助分析，指标预置）。
4. 不含手机原生 App（沿用 Web 响应式，大屏优先适配 PC 大屏分辨率）。
5. 不含对外数据导出/报表引擎（大屏仅在线展示，导出走明细列表）。
6. 学生/家长不做大屏（个人中心即可，避免过度设计）。

## 五、未来 2–3 版本扩展方向 + 权限数据范围表

### 未来版本扩展方向
- **V2.0（自定义布局）**：拖拽式自定义大屏布局编辑器，用户可自定义指标卡/图表位置与组合（对应排除项 1 解除）。
- **V2.1（实时推送）**：WebSocket 实时流式数据推送，异常即时红点提醒，替代定时轮询（对应排除项 2 解除）。
- **V2.2（BI 自助分析）**：拖拽维度自助分析 / 多维透视，用户自建分析视图（对应排除项 3 解除）。
- **V3.0（跨校对比）**：多校区 / 集团校横向对比看板，含跨校趋势与排名（依赖多校版本，见复制包阶段）。

### 权限数据范围表（分角色内容矩阵）

> 大屏数据范围完全继承角色数据权限（docs/04），不另设一套权限。

| 校长 | 全校 | 六域 KPI + 异常：课表完整率、请假/违纪数、采购进度、库存告警、公告已读率、体测达标率、课题结题数 |

## 六、对下游的输入提示

- **设计阶段**：数据大屏作为独立菜单（建议 M15「数据大屏」，挂首页/工作台），各角色进入后按角色渲染预置模板；**趋势图 / 图表区统一放置「学期 / 自然月」维度切换器（默认学期）**；图表库技术选型在 ADR 阶段补充（ECharts / AntV 等）。**指标清单只聚合业务运行数据**——平台级配置类对象（数据字典 M0505、流程模板 M0507、菜单 / 角色 / 部门）**不得作为大屏指标或下钻明细**，此类仅 R-ADMIN 可见（docs/03 注 5）。
- **开发阶段**：大屏聚合接口全部走服务端聚合 + 数据权限过滤（组织型/关系型/角色授权型三类），复用 docs/04 判定算法；缓存策略（Redis 缓存聚合结果，定时失效）。**指标与下钻明细的取数范围不得超出当前角色对目标数据对象的权限**；平台级配置对象（字典 / 流程模板 / 菜单 / 角色 / 部门）一律排除，**服务端聚合时直接过滤，不依赖前端不展示**（对应 AC-DD5-2）。
- **开发阶段（时间口径）**：聚合接口**默认按「当前学期」聚合**（docs/04 §1.8）；自然月维度须在服务端完成学期口径聚合与鉴权**之后**再做月粒度重排——**禁止以自然月作为聚合 / 鉴权主口径**，切换维度不得改变可见性与越权判定结果（对应 AC-DD1-2）。
- **测试阶段**：重点验「分角色看到不同内容」——校长/年级组长/处室/教师四类角色同接口返回数据范围正确；越权数据不出现（40303/40304）；另验「切换学期 / 自然月维度后，同一角色的可见数据集合与越权判定结果完全一致」（AC-DD1-2）。
