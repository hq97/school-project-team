## 一、目标用户与场景（校长 / 体育教师 / 学生 / 家长）

### 校长（管理视角）——要达标率、要成果、要对比
1. **体测达标看板**：全校体测达标率、优良率、年级/班级对比。
2. **赛事成果**：赛事获奖数、项目分布。
3. **器材与训练**：器材借用频次、训练队出勤率。

### 体育教师（执行/管理视角）——要录入快、要借还清、要编排准
1. **体测成绩录入**：分项目录入成绩，≤3 步。
2. **赛事编排与成绩**：报名汇总、赛程编排、成绩记录与公示。
3. **器材台账与借用**：器材入库/借用/归还。
4. **训练队管理**：训练队名单、训练考勤。

### 学生（参与视角）——要能参赛、能查成绩
1. **赛事报名 / 查体测成绩**：本人报名与成绩查询。

### 家长（知情视角）——要能看子女
1. **查看子女体测成绩**：仅本人子女。

## 二、需求清单（REQ-N，标 P0/P1）

### N. 体育
- **REQ-N1｜体测成绩录入**：体育教师分项目录入学生体测成绩（选班级/项目→录入/导入→保存），≤3 步。目标用户：体育教师。P0。
- **REQ-N2｜达标统计**：按国家/校级标准自动计算达标率、优良率、各项目成绩分布。目标用户：体育教师+校长。P0。
- **REQ-N3｜年级/班级对比**：校长查看体测成绩的年级/班级对比与趋势。目标用户：校长。P1。
- **REQ-N4｜赛事报名**：学生/体育教师提交赛事报名（选赛事/项目→填信息→提交），≤3 步。目标用户：学生/体育教师。P0。
- **REQ-N5｜赛程编排**：体育教师编排赛程（项目/场次/时间/场地/参赛人）——**场地取自统一场地对象 space**（`spaceType=SPORT_VENUE`，见 docs/04 §1.11）；提交时**须先读取该「场地 + 时段」的课表占用做冲突校验**（命中则拒绝，见 docs/04 §1.12），合格后再按并发规则竞争同一时段。冲突即时拦截（复用排课冲突校验思路）。目标用户：体育教师。P0。
- **REQ-N6｜成绩记录与公示**：赛事成绩记录、排名、公示，公示期可异议。目标用户：体育教师。P0。
- **REQ-N7｜器材台账**：体育器材入库/台账（统一资产台账 asset，assetType=体育器材；名称/数量/状态/存放点），复用物资台账模板。目标用户：体育教师/R-LOGISTICS。P0。
- **REQ-N8｜器材借用/归还**：教师借用器材（选器材→填数量/用途→提交），≤3 步，归还登记，复用物资领用模板，库存统一在 asset 扣减/回补。目标用户：教师。P0。
- **REQ-N9｜训练队名单**：体育教师维护训练队（队名/队员/训练时间），队员名单管理。目标用户：体育教师。P1。
- **REQ-N10｜训练考勤**：训练出勤记录，出勤率统计。目标用户：体育教师。P1。

## 三、验收标准（含两条硬指标）

**两条硬指标：**
- 硬指标①【校长端】：任一核心体育指标（体测达标率 / 优良率 / 年级班级对比 / 赛事获奖数 / 器材借用频次 / 训练出勤率）无需离开系统去微信或电话追问。
- 硬指标②【高频事务 ≤3 步】：体测成绩录入、器材借用、赛事报名 ≤3 步。

**逐条可测试验收标准：**
- AC-N1-1：体育教师体测成绩录入（选班级/项目→录入或导入→保存）≤3 步。✅硬指标②
- AC-N2-1：系统按标准自动计算达标率/优良率/项目分布，无需手工算。
- AC-N3-1：校长查看体测成绩的年级/班级对比与趋势，无需问体育组。✅硬指标①
- AC-N4-1：赛事报名（选赛事/项目→填信息→提交）≤3 步。✅硬指标②
- AC-N5-1：赛程编排时（同场地同时段/同参赛人同时段）冲突即时拦截。
- **AC-N5-2【补写 C9】**：赛事排期占「场地 + 时段」的并发不超订——多名教师并发提交同一场地同时段仅一人成功（时段原子锁定），其余被拒（对齐 AC-L6-2 / AC-M4-2 / AC-M7-2 写法）。
- **AC-N5-3【补写 场地占用】**：赛程编排提交时（**在并发竞争之前**），服务端先读取该「场地 + 时段」的**课表占用**（docs/06 已发布课表）做冲突校验——命中课表占用一律**拒绝并返回 40901（场地已被课表占用）**，不进入并发判定。**语义区别于 AC-N5-2**：N5-2 是与「其他编排请求」抢同一格（C9 并发），N5-3 是与「已排定的课表」冲突（排课优先单向校验，见 docs/04 §1.12）。
- AC-N6-1：赛事成绩记录与排名，公示期可异议，公示留痕。
- AC-N7-1：器材入库生成台账，可查名称/数量/状态/存放点。
- AC-N8-1：器材借用（选器材→填数量/用途→提交）≤3 步，归还登记，库存自动扣减/回补。✅硬指标②
- AC-N8-2【补写 C9】：体育器材借用库存并发不超卖——多人同时借用最后一件仅一人成功（asset availableQty 原子扣减，见 docs/04 §4.2 D 段）。
- AC-N9-1：训练队名单可维护，队员增删留痕。
- AC-N10-1：训练出勤记录，出勤率统计；校长查看训练出勤率无需问体育组。✅硬指标①

## 四、明确排除项（本次不做什么）

1. 不含体测仪器/穿戴设备对接（成绩由人工录入或表格导入）。
2. 不含赛事直播/电子计时计分系统对接。
3. 不含运动损伤/健康档案（体测仅成绩，不含健康诊断）。
4. 不含课间操排班与教务排课的自动联动（训练队训练时间若与课表冲突，仅提示不联动改课，见边界说明）。
5. 审批沿用固定线性（REQ-D3），不含会签/或签/条件分支/转签/代理。
6. 不含手机原生 App（沿用 Web 响应式）。

## 已确认决策（2026-10-29，用户拍板）

1. **不新增 R-SPORT**：体育域复用 R-SUBJECT（教研组长，体育组）+ R-TEACHER + R-LOGISTICS + 流程模板配置的审批角色。
2. **体测标准 → 国标 + 字典可配置**：达标标准采用国家体质健康标准，同时支持字典可配置（与「处分等级字典可配置」口径一致）。
3. **体育器材 → 统一资产台账 asset**：体育器材纳入统一「资产台账 asset」（assetType=体育器材），与后勤物资、科教实验器材共用底层台账，业务场景独立。
4. **训练队与教务排课 → 仅提示不联动**：训练时间与正式课表冲突时仅提示，不自动改课表（已在排除项）。
