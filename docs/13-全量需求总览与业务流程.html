五条贯穿全平台的主线： ① 审批统一走「流程模板配置的审批角色」（不写死岗位，可配 1~N 级）； ② 数据权限按三种归属类型服务端逐接口校验——组织型（本人/本年级/全校+本班载体）、关系型（家长-子女）、角色授权型（公告）； ③ 后勤物资 / 科教实验器材 / 体育器材合并为统一「资产台账 asset」，借还 / 库存模型一致，业务场景各自独立； ④ 教室 / 实验室 / 会议室 / 运动场地合并为统一「场地对象 space」——课表是场地占用的权威来源，预约提交先过课表占用校验（40901），再并发竞争同一格（40902）；预约不反向阻断排课，双向互斥列 V2.0； ⑤ 统一时间口径：统计与鉴权一律走「学期 + 周次」，趋势图 / 报表提供「学期 / 自然月」切换器，自然月仅为展示维度，不改变数据归属与越权判定（docs/04 §1.8）。
